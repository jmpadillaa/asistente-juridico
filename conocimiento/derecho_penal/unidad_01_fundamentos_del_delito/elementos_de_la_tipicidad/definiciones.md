# Definiciones: Elementos de la tipicidad

| Término | Definición | Fuente |
|---|---|---|
| Tipo penal | Descripción abstracta de la conducta que formula la ley | Diap. S3 |
| Tipicidad | Juicio de adecuación del hecho concreto a todos los requisitos del tipo | Diap. S3 |
| Verbo rector | Núcleo del tipo; delimita la conducta (matar, sustraer, falsificar) | Diap. S3 |
| Sujeto activo | Quien realiza el hecho, a veces con una calidad especial | Diap. S3 |
| Sujeto pasivo | Titular del bien jurídico protegido | Diap. S3 |
| Bien jurídico | Interés que protege la ley | Diap. S3 |
| Objeto material | Persona o cosa sobre la que recae la acción | Diap. S3 |
| Elemento descriptivo | Se identifica con datos observables | Diap. S3 |
| Elemento normativo | Exige valoración jurídica o social ("ajeno", "servidor público") | Diap. S3 |
| Imputación objetiva | Atribución jurídica del resultado al autor por un riesgo desaprobado realizado en el resultado | Diap. S3; Clase 3 |
| Dolo (art. 26) | Conocimiento de los elementos objetivos del tipo y ejecución voluntaria de la conducta | Diap. S3 |
| Culpa (art. 27) | Infracción del deber objetivo de cuidado personalmente exigible que produce un resultado dañoso previsto como infracción culposa | Diap. S3 |
| Error de tipo (art. 28.1) | Desconocimiento o comprensión equivocada de un elemento objetivo del tipo | Diap. S3 |
