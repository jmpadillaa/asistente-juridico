# Prompts reutilizables

Cada archivo es una indicación lista para pegar al iniciar una tarea con el agente correspondiente. Cambia lo que está entre `<corchetes>`. Todos asumen las reglas de `CLAUDE.md` (español, priorizar al docente, señalar preguntas de examen) y de `documentacion/guia_de_entregables.md`.

| Archivo | Agente | Cuándo usarlo |
|---|---|---|
| `01_analizar_guia.md` | Analista de Guías | Guía o sílabo nuevo |
| `02_analizar_clase.md` | Analista de Clases | Transcripción o diapositivas nuevas |
| `03_actualizar_conocimiento.md` | Gestor de Conocimiento | Después de un resumen de clase |
| `04_material_de_estudio.md` | Constructor de Material | Hoja de repaso, cuadros, glosario |
| `05_simulacro_y_flashcards.md` | Preparador de Exámenes | Antes de una evaluación |
| `06_plan_semanal.md` | Planificador Académico | Cada lunes o antes de una evaluación |
| `07_entregable.md` | Director + Constructor | Cualquier foro, infografía, mapa, informe o ensayo |
| `08_investigar_pendientes.md` | Investigador Académico | Normas o fuentes por verificar |
