# Asistente Académico Jurídico

## Objetivo General

Crear un sistema de estudio basado en agentes de IA para apoyar el aprendizaje universitario en Derecho.

El sistema analizará:

- Guías de estudio
- Subtítulos de clases
- Bibliografía obligatoria
- Bibliografía complementaria
- Actividades académicas
- Evaluaciones

## Idioma

Todo el sistema debe trabajar exclusivamente en español.

## Agentes del Sistema

1. Director Académico
2. Analista de Clases
3. Analista de Guías
4. Investigador Académico
5. Gestor de Conocimiento
6. Constructor de Material de Estudio
7. Preparador de Exámenes
8. Planificador Académico

## Principios

- Mantener el conocimiento organizado.
- Priorizar información proporcionada por los docentes.
- Señalar posibles preguntas de examen.
- Generar materiales de estudio reutilizables.
- Crear una base de conocimiento jurídica permanente.
